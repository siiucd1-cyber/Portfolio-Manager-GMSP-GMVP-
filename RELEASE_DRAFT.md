# v1.0.0 - Portfolio Optimization App with Leverage Advisor

This release introduces a bilingual Streamlit-based portfolio optimization application for quantitative finance and investment analytics.

Key features:

- Markowitz portfolio optimization
- Global Minimum Variance Portfolio (GMVP)
- Efficient Frontier visualization
- Maximum Sharpe Ratio portfolio
- Backtesting module
- Asset allocation output
- Risk profile settings
- Leverage Advisor based on fractional Kelly, drawdown constraints, and historical stress testing

This project is published for demonstration and portfolio purposes. It does not constitute investment advice.
